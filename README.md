# Daniel Wang — Academic Portfolio

A responsive, dependency-free academic website designed for GitHub Pages.

## Personalize the site

Add a CV later by placing `Daniel-Wang-CV.pdf` in the repository, then add a link to it in
the hero or navigation.

## Publish on GitHub Pages

1. Use the public repository named `danieldaidai.github.io`.
2. Push this folder to the repository's `main` branch.
3. Keep **Settings → Pages → Build and deployment** set to **Deploy from a branch**,
   with the `main` branch and `/ (root)` folder.
4. GitHub Pages publishes the site after each push. No build workflow is required.

Your website will be available at `https://danieldaidai.github.io`.

## Public Knowledge Garden

The selected-work section links to the public [Knowledge Garden](https://danielfortruth.com)
and its [knowledge entries](https://danielfortruth.com/knowledge/). That site is hosted
separately; keep this repository's existing GitHub Pages address. Do not add a `CNAME`
for `danielfortruth.com` here.

This homepage contains public profile information and project links only. Research notes,
paper records, and original source files belong in the separate private content repository.

## Local preview

You can open `index.html` directly in a browser. No package installation or build step
is required.
